# US-063 — Pannello compatto della preview

Aprire `index.html` direttamente nel browser. File standalone senza dipendenze o rete.

Direzione: stessa cornice carta e indaco dell'app attuale, densità da strumento di lavoro. La distinzione visiva principale è l'elenco delle richieste in righe, con un solo editor aperto.

- Trascinare il separatore oppure focalizzarlo e usare Su/Giù (20 px), Home/End.
- Premere Commenti/Output per cambiare contenuto e ripristinare il pannello ridotto.
- Riduci lascia le tab; Nascondi lascia Apri pannello nella toolbar.
- Hover o modifica di una riga evidenzia il componente numerato nella preview.
- Aggiungi commento, poi selezione del titolo, scheda o pulsante nella preview, apre un editor vuoto; l'invio resta disabilitato finché non si scrive.
- Simula errore aggiunge una riga all'output e un badge senza cambiare tab o focus.
- ⛶ usa il fullscreen nativo; Esc ritorna alla finestra.
- Provare a 390 px: toolbar e azioni rimangono raggiungibili, nessuno scroll orizzontale della cornice.

Limiti deliberati del prototipo: output e invio simulati; dati mantenuti in memoria; tre target dimostrativi sulla stessa pagina. Non include persistenza, bridge produzione, regole del processo o gestione server.
