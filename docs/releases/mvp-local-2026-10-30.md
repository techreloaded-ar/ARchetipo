# Prima versione locale: collaudo e consegna

30 ottobre 2026. Obiettivo di consegna: 31 ottobre 2026.

## Perimetro

MVP locale: descrivere un problema, provare l'app, dare feedback e consegnare ai
developer un candidato verificato. Configurazione reale collaudata: macOS, Codex
nativo, backlog file e Git. PRD e backlog popolato sono facoltativi. Il viewer
non esegue merge o deploy. Worktree e ricette separano il lavoro locale; non sono
isolamento di sicurezza del sistema operativo.

## Avvio della build candidata

Nel repository ARchetipo, da un commit pulito:

```sh
npm run install:dev
archetipo version
```

Conservare versione e hash SHA-256 dei due `.tgz` prodotti in
`.dev/npm-staging/`: il pacchetto pubblico npm può ancora essere precedente.
Go serve per costruire la build, non per eseguire il binario distribuito.

Nel progetto:

```sh
archetipo init --tool codex --connector file
archetipo view
```

Codex deve essere installato e autenticato. Sceglierlo come provider nelle
impostazioni del workspace; modello e permessi provengono dal runtime. I permessi
si rispondono nel viewer. Per la PR servono anche `gh` autenticato e un remote
accessibile. Senza hosting si può comunque provare l'app, conservare il candidato
ed esportare il dossier. Per un'app esistente versionare prima i sorgenti in Git;
è supportato anche il workspace vuoto per una nuova app.

Non cancellare dati storici per aggiornare una versione incompatibile: serve una
migrazione esplicita. Questa prova parte da un'installazione nuova e dati sintetici.
